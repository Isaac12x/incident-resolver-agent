# Review Comments

- Read complete review threads and inspect the referenced code before responding.
- Ignore bot loops and comments from unauthorized authors.
- Distinguish requested code changes from questions or informational comments.
- Make and test requested changes before replying.
- Resolve a thread only after the requested behavior is verified.
- Summarize the change and the verification in the reply.
